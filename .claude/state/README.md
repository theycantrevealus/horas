# Task state files

State of the work in progress, so a new chat continues where the last one stopped. Rules: `../rules/task-state.md`.

- `<branch>.md`: one per branch, from `TEMPLATE.md`. Deleted after the branch is merged.
- `series--<master plan>.md`: one per plan built over several branches, from `SERIES-TEMPLATE.md`. Deleted when the plan is finished.

Only this README and the two templates are committed. The state files themselves are ignored by git and stay on the developer's machine.
